# Resale Pricing POS List Update

The Resale Pricing module has been changed from product cards to a dense point-of-sale update list.

## Unit-facing changes
- Nett cost is no longer shown in the Resale Pricing price book.
- The dashboard Resale Pricing preview no longer shows nett cost.
- Products are displayed as compact rows so substantially more items can be viewed at once.
- The list columns are Item Code, Product / Pack, Category and Selling Price.
- Selling Price is visually emphasised for fast POS updates.
- Search, category browsing, unit/category allocation, print/PDF and access controls remain unchanged.
- Underlying nett-cost data and pricing calculations are retained in the data model; only the unit-facing display was removed.
