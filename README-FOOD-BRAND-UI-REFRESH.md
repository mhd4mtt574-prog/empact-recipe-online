# Food by Empact Group UI refresh

This build applies a shared brand-led visual system across the application without changing the underlying recipe, resale pricing or compliance business logic.

## Brand direction applied

- Food by Empact Group wordmark retained as supplied artwork.
- Primary digital palette: Empact turquoise, graphite and white.
- Food yellow used as the divisional supporting accent, especially for price emphasis and Food pattern details.
- Arial is used as the approved fallback typeface because the application package does not distribute the proprietary Gilroy font files.
- Ripple-inspired circular motifs are used as subtle interface decoration.
- The Food pattern is represented as a restrained background device rather than a dominant UI texture.
- Layouts favour clean white space, simple iconography, clear hierarchy and large touch-friendly controls.

## Updated areas

- Global top navigation and user area.
- Main dashboard / landing page.
- Resale Pricing converted to a price-book card layout.
- Administrator compliance dashboard re-skinned to the combined executive-summary + analytics visual direction.
- Existing forms, buttons, cards and supporting screens inherit the refreshed palette and spacing.

## Functional behaviour retained

No pricing rules, unit/category allocation logic, user authentication, compliance calculations, recipe calculations or audit behaviour was intentionally changed as part of this UI refresh.
