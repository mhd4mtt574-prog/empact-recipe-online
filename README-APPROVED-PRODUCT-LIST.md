# Approved Product List feature

Administrator and Head Office users now have an **Approved products** navigation tab.

- Products are identified by a unique product code.
- Editing an approved product cost automatically updates every linked recipe ingredient.
- Affected recipe totals, portion costs and recommended selling prices recalculate automatically.
- Existing ingredient lines are migrated to stable generated APL codes on first launch.
- Recipe ingredient format supports: `Product Code | Ingredient | Quantity | Unit | Unit Cost | Waste %`.
- The original five-field ingredient format remains accepted for backward compatibility.
