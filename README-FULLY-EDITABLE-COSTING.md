# Fully editable costing template

Administrator recipe editing now permits changes to every clean-costing column, including APL code, product, pack size, purchase price, factor, standard quantity, batch issue, waste factor, batch cost and cost per portion.

Columns J-M continue to calculate from the clean costing formulas by default. Typing in one of these cells creates a saved manual override. The row reset button restores formulas for one row, while **Use formulas for all rows** clears all overrides.
