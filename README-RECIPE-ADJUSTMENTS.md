# Recipe adjustments

The administrator navigation now uses **Recipe adjustments**.

The page includes:

- Recipe item replacement for a selected exact ingredient name.
- Move to lower comparable product, which previews and then bulk-replaces linked recipe items only when an active approved product has the same division, compatible normalized unit, matching product-family wording, and a lower R/kg, R/L or R/each cost.
- Audit history for all bulk replacements.

Recipe quantities, recipe units, preparation notes, factors, costing overrides, portions and unit GP margins are preserved.
