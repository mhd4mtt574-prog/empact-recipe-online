# Menu item replacement

Administrators can use **Menu adjustments > Menu item replacement** to replace an exact ingredient name across all recipes with an active Approved Product List item.

The tool:
- shows the number of affected recipes and ingredient lines;
- requires explicit confirmation;
- preserves recipe quantities, units, cooking notes, conversion factors and costing overrides;
- updates the ingredient name, APL product link, division, code, pack information and current approved price;
- marks every affected recipe as administrator-corrected so upgrades do not overwrite it;
- increments recipe versions and records an audit history and activity log.
