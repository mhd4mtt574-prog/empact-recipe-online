# Branded UI update

This release refreshes the application look and feel with:
- Food by Empact branded sidebar navigation
- Responsive mobile navigation
- Redesigned login screen
- Dashboard metrics, quick actions and recent recipe cards
- Modern recipe library filters and cards
- Structured four-step recipe editor with sticky save panel
- Ingredients, allergens, checks, units, users, reports and settings screens
- Updated print-friendly recipe sheet styles

The new operational screens are presentation-ready foundations. Recipe checks, user/unit creation and settings persistence remain future functional modules.
