# Recipe Checks

Adds automatic checks for recipe identity, departments, portions, method, ingredient completeness, duplicate lines, quantities, prices, APL codes and links, inactive products, possible best-value alternatives, cost per portion, GP margin, selling-price integrity, allergens, serving/yield guidance, review age, duplicate recipes and major portion variance.

Critical failures block approval. Administrators can filter the Recipe Checks page and open the recipe directly for correction. Warnings permit approval but remain visible for review.
