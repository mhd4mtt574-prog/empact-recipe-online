# APL item-code auto lookup

The recipe costing grid now supports two APL workflows:

1. **Search APL Ingredients** — search and select one or more approved products.
2. **Paste/type an item code** — entering an exact APL code in the first column automatically fills product name, pack size, purchase price, factor, and unit of measure for the selected costing division.

Cooking notes, standard quantity, and any manually overridden formula columns are preserved. If no exact APL code is found, the row remains fully editable as a manual ingredient.
