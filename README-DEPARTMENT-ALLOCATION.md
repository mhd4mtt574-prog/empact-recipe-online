# Department costing groups and recipe allocation

The recipe library is grouped into: Beef, Fish, Chicken, Lamb/Mutton, Pork, Salad, Starch, Grains, Desserts, Vegetables and Pastas.

Administrators can use **Allocate recipes** from the recipe library to move any recipe to another department. Allocation changes only the department; recipe ingredients, APL links, costs, portions, approval state and history remain intact. Existing installations are backfilled automatically from recipe category and name, while all new and edited recipes include a department selector.
