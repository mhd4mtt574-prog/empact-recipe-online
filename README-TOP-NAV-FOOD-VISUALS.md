# Top navigation + Food visual refresh

This update keeps the existing operational page structures and business logic intact while applying the approved visual direction:

- Primary navigation remains at the top across authenticated pages.
- Reports is labelled **Reports & Tie-back**.
- Administrators get a direct **Compliance** top-nav item; the remaining administrator tools stay grouped under **Admin**.
- Dashboard, Resale Pricing, Food Waste and Compliance use restrained Food by Empact food imagery in their page headers.
- Existing forms, tables, dashboard cards, POS list, compliance calculations and access rules are unchanged.
- Responsive rules remove the decorative imagery on narrower screens to protect usability.

The decorative food artwork is generated artwork packaged inside `wwwroot/images/food-accents` and does not alter application data.
