# Administrator User Management

Adds a visible **Administration > User Management** screen for administrator accounts.

## Functions
- Search by username, unit code, display name, email or unit.
- Filter by role and active/inactive status.
- View username, role, linked unit, region and password-change status.
- Reset a user's password to the temporary password `Empact@2026!`.
- Every reset sets `MustChangePassword = true`, so the user must change it after their next successful login.
- Activate or deactivate accounts.
- Prevent the currently signed-in administrator from deactivating their own account.
- Password reset and account activation/deactivation are written to the application activity/audit history.

## Security
The temporary password is never stored in plain text. A PBKDF2-SHA256 hash and new random salt are generated by the existing PasswordService on every reset.
